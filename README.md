# ClockOS

Lightweight clock firmware designed for the Arduino Nano.

## Latest version

**ClockOS 2.0 — Phoenix**

Released: 24 November 2026

## Features

- COS2 startup logo
- 12-hour time display
- Automatic recovery environment
- Safe mode
- Serial command interface
- RTC diagnostics
- Manual time setting
- Software clock fallback
- Persistent error logging
- Adjustable brightness
- Factory settings reset

## Supported hardware

- Arduino Nano (ATmega328P)
- DS3231 RTC module
- HW-069 TM1637 display

## Required libraries

- RTClib by Adafruit
- TM1637Display by Avishay Orpaz

## Getting started

Upload the firmware using Arduino IDE. Open Serial Monitor at 9600 baud with Newline selected.

Enter `HELP` to view available commands.
