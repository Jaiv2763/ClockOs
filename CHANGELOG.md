# Changelog

All notable changes to ClockOS will be documented in this file.

## [2.0.0] — Phoenix

Release date: 2026-11-24

### Added
- COS2 startup logo.
- Serial command-line interface.
- Automatic recovery environment.
- Basic safe mode.
- Manual time configuration.
- Software clock fallback.
- Persistent EEPROM error logging.
- Adjustable brightness.
- Factory settings reset.
- System uptime and version information.
- RTC, RAM and display diagnostics.
- Error codes E000–E006.

### Improved
- RTC communication and validation.
- 12-hour time display.
- RTC freeze detection.
- Automatic time retrieval during startup.
- Invalid command handling.

### Known limitations
- Safe mode does not isolate faulty hardware.
- Software reboot is not implemented.
- Display diagnostics require visual inspection.
- Software clock cannot retain time after power loss.
